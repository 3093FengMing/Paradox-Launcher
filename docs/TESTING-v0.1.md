# v0.1 测试指南

本轮先交付可独立运行的 Windows x64 测试版，验证基础界面、配置和原版流程。版本目录缓存、Java 检测页、下载队列等 v0.2 功能暂缓；完整游戏兼容矩阵尚未验收。

## 运行环境与文件

测试文件位置：`releases/v0.1.0/Paradox-Launcher-0.1.0-windows-x64.exe`。构建和校验的实际结果见 [验证记录](VERIFICATION.md)。

- Windows x64 与 [Microsoft WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。
- 运行发布版不需要 Rust、Node.js、npm 或 Vite 服务；前端资源内嵌在 exe 中。
- 查询目录和安装游戏需要网络。启动 Minecraft 需要对应版本的本地 Java，测试版不自动下载 Java。

可先使用以下组合逐项测试；它们是兼容性验收目标，不表示本版本已完成这些游戏测试：

| Minecraft | Java    | 测试目的     |
| --------- | ------- | ------------ |
| 1.12.2    | Java 8  | 较旧原版流程 |
| 1.20.1    | Java 17 | 中间版本流程 |
| 1.21.1    | Java 21 | 较新原版流程 |

在“设置与个性化 → 游戏与 Java”中填写 Java 可执行文件的绝对路径；留空时由 Elemental 搜索兼容的本地运行时。不同游戏版本的运行要求应以该版本信息为准。

## 测试数据隔离

默认配置位于 `%LOCALAPPDATA%/ParadoxLauncher/config.json`，默认游戏目录为同目录下的 `minecraft/`。实例使用独立 UUID 目录，显示名称可以改变。

建议使用独立配置进行测试，保存设置前将游戏目录也改到测试目录。只设置 `PARADOX_CONFIG` 会隔离配置文件，不会自动改动默认游戏目录。

```powershell
$env:PARADOX_CONFIG = "$env:LOCALAPPDATA\ParadoxLauncher-v01-test\config.json"
& '.\releases\v0.1.0\Paradox-Launcher-0.1.0-windows-x64.exe'
```

不设置环境变量时，可以直接双击 exe。首次启动应显示空实例库，不自动注入演示游戏。

## 界面与持久化

1. 确认能打开首页、我的实例、版本下载、账户管理、设置和运行日志。
2. 在外观设置中切换“沉浸主页”和“现代工作台”，确认实例与账户数据一致。
3. 修改主题、强调色、缩放、圆角、背景开关、模糊、遮罩、侧栏不透明度和减少动效。修改应即时预览，“还原修改”应恢复已保存的值。
4. 点击“保存设置”，关闭并重新打开程序，确认样式和设置保留。
5. 创建两个不同版本的实例，切换当前实例，重命名其中一个。名称应更新，实例存储位置应保持不变。
6. 检查实例菜单的方向键、Enter 和 Escape，以及创建表单的初始焦点、Tab 导航和关闭操作。

背景当前为 CSS 图层和本地占位 SVG，测试重点是布局与设置是否生效。窗口渲染、窗口按钮和高 DPI 的人工测试可由测试者补充；本轮开发验证按用户要求未执行原生渲染验收。

## 账户、版本目录与错误

1. 保存合法离线用户名，重启确认保留；输入不合法名称时应明确报错。
2. 在版本下载页获取真实目录，搜索版本号，切换快照显示，并从结果创建实例。
3. 断网后刷新目录，确认显示网络错误且可以重试，不展示伪成功。
4. 输入相对游戏目录、不合理内存或分辨率，保存应被拒绝，原配置保持有效。
5. 保存后退出程序，备份测试配置。使用备份副本检查损坏 JSON 或不支持的 schema：重新打开程序应显示配置错误，仍可关闭窗口，原文件不应被覆盖。恢复有效配置后重新启动程序。

配置加载失败时，宿主保留启动错误并拒绝配置写入；错误页面不会偷偷使用默认配置替换原数据。

## 原版安装与启动

1. 选择一个兼容性目标，在独立游戏目录创建原版实例，检查 Java 路径和内存设置。
2. 点击“安装游戏”。任务进行中应阻止冲突的配置写入与实例操作；安装失败应展示错误，允许任务结束后重试。
3. 安装完成后点击“启动游戏”。没有合适 Java 或实例文件不完整时，应显示实际错误；不应隐式重复下载。
4. 游戏启动后查看运行日志，确认任务状态和游戏输出。使用“停止游戏”结束进程；成功停止应显示完成状态。
5. 自然退出游戏后，再次启动同一实例，确认实例仍可用。

安装／启动已接入 Elemental，但本轮尚未完成干净目录下的完整游戏下载、启动、退出、再次启动及故障矩阵。当前安装只展示真实任务阶段，没有文件／字节百分比、取消按钮或下载队列。

关闭启动器目前不会自动结束运行中的 Java。结束测试前建议先在启动器内点击“停止游戏”，再关闭窗口。

## 日志与反馈

日志最多保留最近 500 条，可在运行日志页导出文本。反馈问题时记录 exe 版本、Windows 与 Java 版本、Minecraft 版本、触发步骤、错误文本和相关日志。共享前先检查日志与路径中的个人信息。

只读诊断参数为 `--version`、`--help`、`--check-catalog` 和 `--inspect`；目录查询与扫描会读取指定配置。发布版隐藏控制台，可在终端中重定向诊断输出。
