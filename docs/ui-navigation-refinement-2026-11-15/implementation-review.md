# 导航、密度与交互收尾

本轮在已批准的“折页布局＋石墨配色”上实施用户的具体反馈。沉浸式与 Modern 仍各有9个业务路由、45个可替换视图，使用同一个永久 LauncherProvider 和真实公开动作。来源基线为 `e3e880f397ad3d22dc5301819b8832d9f672cb86`；该提交的原截图和验收记录保留在 `docs/ui-redesign-2026-11-15/`。

## 实际变化

| 范围 | 结果 |
| --- | --- |
| 沉浸式主导航 | 首页、我的实例、下载、设置四主入口；次要入口进入更多。≤900px使用完整导航菜单，取消横向导航滚动。品牌名与版本按同一基准对齐。 |
| 沉浸式首页 | 启动下拉箭头朝下，菜单首选下方并允许小窗碰撞翻转。实例设置入口靠近实例名称，收紧左右工作面间距。 |
| 统一下载 | 两套均从“下载”进入游戏版本或资源，任务记录只呈现一个真实下载队列。普通主导航没有重复的资源/任务入口。 |
| 下载活动 | 右下角图标仅在公开active或pending下载状态出现；终态若仍获焦则暂留到失焦，防止焦点丢失。小窗启动/选择按钮为它预留空间。任务记录继续支持失败重试。 |
| 账户 | 两套从首页账户按钮进入管理，普通主导航不再放账户入口。路由和启动页选择能力保留。 |
| 我的实例 | 常规列表与compact查看栏不直接显示目录；完整详情、设置和删除失败诊断仍可查看路径。筛选器加宽，小窗按整行重排。 |
| 版本库 | 两套连续列表，搜索为唯一版本文本入口，类型使用公共Select下拉；初始30条，更多每次30条，搜索/筛选/目录变化后回到首批。 |
| 版本加载边界 | 现有后端仍获取可缓存的完整目录索引；本轮减少初始DOM行数，按用户操作渐进呈现。没有新增服务器分页或逐版本后台预加载。 |
| Modern首页 | 移除内存/分辨率摘要、重复资源快捷和任务摘要；活动只显示一次。宽容器左侧实例概要、右侧账户与启动动作，≤700px工作面改回单列。 |
| Modern窗口与设置 | 独立顶栏始终可见。低高度侧栏改图标或菜单，保持全入口可达且无导航滚动条。实例设置输入填满字段容器，外padding为1em。 |
| 日志 | 1.4行高、每行2px纵向padding，保留换行、选择、导出、过滤与跟随；INFO/WARN/ERROR等使用主题语义色并保留书面级别。 |
| 控件 | 补足操作图标及图标按钮边界，输入、次动作与核心工作面使用公开圆角。支持时用CSS corner-shape:squircle，旧环境保留普通圆角。 |
| 动效 | hover颜色/边框150ms、按下45ms；路由170ms短透明度过渡，不重挂载业务Viewport/provider，不改变固定启动条的包含块。应用/系统减少动效均关闭相应反馈。 |

## 新独立审查

用户要求“完成后新开子代理或对话复查”，已新建未参加实施的 `/root/independent_ui_review`。它发现2项P2和2项P3，全部由主代理修复后重新复验：Modern首页空间分布、compact查看栏目录、核心表面连续曲率、版本类型下拉对齐。桌面卡片实际高度141.5px，640px回到单列；核心表面computed squircle；Select Enter/Escape真实返回焦点。受检范围没有剩余可复现P0/P1/P2。

详细发现和检查边界见 [independent-review.md](independent-review.md)。
