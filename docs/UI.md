# UI 与自定义设置

更新日期：2026-10-26。双样式、完整外观预设与简体中文 / English 已在 v0.2 实现。

## 两种界面风格

默认「沉浸式」参考用户提供的布局：全窗口背景、半透明左侧栏、紫蓝色标题栏、右下角分体启动按钮与实例选择菜单。首页留出大面积背景，其他页面使用可读的内容面板。账户、游戏与常用设置入口保持明确层级。

「现代工作台」保留现有石墨灰界面、蓝色强调色、卡片式启动区、实例库与启动偏好。两种样式共用实例、设置、下载与运行状态；切换样式不会创建另一套数据。

在「设置与个性化 → 外观与体验」通过风格卡片切换，设置页即时预览。点击「保存设置」后，下一次启动继续使用已保存的样式。

背景当前使用 CSS 图层与本地占位图片：沉浸式默认加载 `background-placeholder.png`，现代工作台使用现有 SVG 风景。素材仍用于占位，未裁切参考截图作为资源；背景文件选择与正式素材列入后续扩展。

桌面初始窗口为 1240 × 720，采用 38px 自绘标题栏，允许自由调整大小，不设置应用级最小或最大尺寸。应用高度固定到视口，标题栏与侧栏保持稳定，正文在内容区域独立滚动；切换页面时正文回到顶部。长列表、侧栏与弹窗使用透明轨道和随主题变化的细滚动条，悬停或键盘焦点进入时提高对比度。较矮窗口自动缩小侧栏间距，设置、日志入口仍可滚动访问。

最小化、最大化 / 还原与关闭由 Tauri 窗口 API 实现。前端同时适配窄视窗供浏览器预览，浏览器中的窗口控制禁用。

浏览器已验证 640 × 480 与 320 × 240，在 120% 缩放下设置与预设操作区可折行，页面和预设卡片没有横向溢出。原生已验证最大化 / 还原、现代样式重启恢复及 Alt+F4 正常退出；鼠标任意尺寸拖动、完整原生视觉、高 DPI 与任务运行期间全部关闭分支仍需验收。

## 交互与设计实现

界面实现参考已安装的 [emilkowalski/skills](https://github.com/emilkowalski/skills/tree/2d228630ba1446365f614a108cb8252f1feda202)，主要使用 `emil-design-eng` 与 `ask-sonner` 的设计规则。

- Base UI 管理创建 / 重命名对话框、实例菜单的焦点与键盘交互。
- Sonner 显示保存成功、任务结果与错误；错误仍可在对应页面或日志中查看。
- 按钮使用短促按压反馈，弹层使用 transform / opacity 过渡。
- 键盘导航保留清晰焦点并减少过渡；支持系统 `prefers-reduced-motion` 和应用内减少动效设置。
- 开关提供 ARIA role 和当前状态，图标按钮提供可读名称，长实例名称有换行或截断处理。
- 通用 `LauncherDialog` 统一实例设置、导入、移除和关闭请求弹窗，保持主题、焦点与待处理状态一致。

## 外观预设与语言

「保存当前外观」可保存全部 11 项外观参数，名称支持 1–48 个 Unicode 字符，包括中文和 emoji。预设可应用、重命名、移除与导出为可移植 JSON，导入生成新 ID。预设只保存外观，语言、账户、实例、目录与网络设置保持独立。

预设库操作立即持久化，不提交尚未保存的设置草稿；「应用」先预览该外观，点击「保存设置」后下次启动才继续使用。移除预设不改变当前外观。导入采用严格版本与字段校验，限制 32 KiB 文本，错误时保留原有预设。

语言在「外观与体验」顶部选择，页面、弹窗、常用提示、ARIA 名称与表单校验即时切换。跟随系统响应支持语言的系统变化；显式选择简体中文或 English 后保持用户选择。Minecraft 日志、路径、版本与玩家命名保留原值。

资源由 `i18next` / `react-i18next` 随 exe 离线提供；`npm run check:i18n` 已加入 CI，检查 502 个资源键、插值一致性与 420 处静态调用。使用、格式与扩展方式见 [CUSTOMIZATION-I18N.md](CUSTOMIZATION-I18N.md)。

## Java 与实例管理

「游戏与 Java」提供本地检测、可执行文件选择和当前路径检查。结果显示主版本、vendor、架构、来源与路径，可写入全局 Java 设置；留空时由启动器匹配实例元数据要求的主版本与当前平台架构。检测失败位置以警告显示，不丢弃其他成功结果。

Java 8 / 17 / 21 提供快捷下载，也可填写 8–99 的其他主版本。当前下载支持 Windows x64 / ARM64 的 Adoptium JRE，任务进入共用下载队列；下载完成后校验文件和实际版本，再刷新检测结果。不可用平台或主版本显示具体原因。

实例设置支持名称与 Java、最小 / 最大内存、分辨率、JVM / 游戏参数覆盖。每项单独控制是否覆盖；关闭覆盖继承全局，启用空 Java 路径表示自动选择，启用空参数表示清除该项全局参数。已有实例的游戏版本与存储根目录在编辑中只读，更换外部根目录需重新导入。

导入弹窗选择完整游戏根目录，扫描并勾选 Vanilla 实例，引用原文件而不复制资源；导入的外部根目录保持独立。移除弹窗默认仅删除启动器记录，文件删除需勾选并输入完整实例名称；文件操作保留共享 assets / libraries，并拒绝危险的共享目录或链接路径。

## 下载与关闭状态

下载页同时展示会话任务队列与版本目录。队列以等待、下载、取消中、已取消、已完成、失败表示状态；显示文件数、复用数、实际传输、速度与当前文件。有可靠总大小时显示字节百分比，否则显示待确认的总大小和文件进度。

队列任务依次执行，单任务中的文件按设置并发下载。等待或运行中的任务可取消，已取消 / 失败任务可重试；正在下载时阻止配置修改和游戏启动，但可追加其他下载任务。重启后从安装 / 修复恢复，复用已校验完整文件，任务历史不跨会话持久化。

版本目录显示网络 / 缓存来源与获取时间。缓存过期或刷新网络失败时保留可用目录，并显示警告与重试入口。

游戏或下载运行中默认弹出关闭选择：返回启动器、隐藏窗口继续任务、停止任务并退出。隐藏后任务结束会退出，再次启动同一 exe 可唤回窗口；停止失败或超时保留窗口并说明原因。

## 状态规范

- 空实例库显示创建入口，不伪造示例或历史记录。
- 配置创建成功后显示「待安装」；磁盘扫描命中才显示「已安装」。
- 右下启动区沿用实际安装 / 启动决策，菜单可切换当前实例、创建新实例或进入实例管理。
- 安装与启动显示真实阶段；下载使用实际字节 / 文件进度，不为元数据解析或解压编造百分比。
- 网络失败展示错误与重试；列表可手动刷新，不默认进行大文件下载。
- 网页预览显示模式标识；安装 / 启动、本地 Java 检测与文件选择禁用。
- 运行中的游戏提供停止入口；主动停止成功作为正常完成处理，崩溃与异常退出报告错误。
- Microsoft / loader 功能显示 roadmap 阶段，避免暗示已实现。
- 参考图中的更新通知没有被当作已实现功能。
- 设置 draft 与已保存配置分离；离开设置页不会自动保存，「还原修改」撤销未保存的调整。
