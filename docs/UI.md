# UI 与自定义设置

## 两种界面风格

默认「沉浸式」参考用户提供的布局：全窗口背景、半透明左侧栏、紫蓝色标题栏、右下角分体启动按钮与实例选择菜单。首页留出大面积背景，其他页面使用可读的内容面板。账户、游戏与常用设置入口保持明确层级。

「现代工作台」保留现有石墨灰界面、蓝色强调色、卡片式启动区、实例库与启动偏好。两种样式共用实例、设置、下载与运行状态；切换样式不会创建另一套数据。

在「设置与个性化 → 外观与体验」通过风格卡片切换，设置页即时预览。点击「保存设置」后，下一次启动继续使用已保存的样式。

背景当前只使用本地占位 SVG 和 CSS 图层。沉浸式的天空、海面与方块岛屿是占位素材，现代工作台继续使用现有 SVG 风景；没有生成正式背景，也没有裁切参考截图作为资源。背景文件选择与正式素材列入后续扩展。

桌面初始窗口为 1240 × 820，最小 980 × 700，采用 38px 自绘标题栏。最小化、最大化 / 还原与关闭由 Tauri 窗口 API 实现。前端同时适配窄视窗供浏览器预览，浏览器中的窗口控制禁用。

## 交互与设计实现

界面实现参考已安装的 [emilkowalski/skills](https://github.com/emilkowalski/skills/tree/2d228630ba1446365f614a108cb8252f1feda202)，主要使用 `emil-design-eng` 与 `ask-sonner` 的设计规则。

- Base UI 管理创建 / 重命名对话框、实例菜单的焦点与键盘交互。
- Sonner 显示保存成功、任务结果与错误；错误仍可在对应页面或日志中查看。
- 按钮使用短促按压反馈，弹层使用 transform / opacity 过渡。
- 键盘导航保留清晰焦点并减少过渡；支持系统 `prefers-reduced-motion` 和应用内减少动效设置。
- 开关提供 ARIA role 和当前状态，图标按钮提供可读名称，长实例名称有换行或截断处理。

自定义背景文件、字体、快捷键、语言、主题预设与应用行为列入后续里程碑。

## 状态规范

- 空实例库显示创建入口，不伪造示例或历史记录。
- 配置创建成功后显示「待安装」；磁盘扫描命中才显示「已安装」。
- 右下启动区沿用实际安装 / 启动决策，菜单可切换当前实例、创建新实例或进入实例管理。
- 安装与启动进程显示真实阶段；字节进度未接入前不展示百分比。
- 网络失败展示错误与重试；列表可手动刷新，不默认进行大文件下载。
- 网页预览显示模式标识，安装 / 启动禁用。
- 运行中的游戏提供停止入口；主动停止成功作为正常完成处理，崩溃与异常退出报告错误。
- Microsoft / loader 功能显示 roadmap 阶段，避免暗示已实现。
- 参考图中的更新通知没有被当作已实现功能。
- 设置 draft 与已保存配置分离；离开设置页不会自动保存，「还原修改」撤销未保存的调整。
