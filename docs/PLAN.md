## 自定义设置原则

每个公开设置应实际影响行为并保存。外观设置即时预览，保存后持久生效；游戏与网络设置保存后用于下一次任务。切换全局游戏根目录不迁移原文件，导入实例保留外部根目录引用。

每实例覆盖未启用时继承全局；显式启用空 Java 路径代表自动选择，空附加参数代表清除该项全局参数。内存通过专门字段配置，JVM 参数不能再次设置冲突的内存参数。

两种界面共用配置、实例与下载状态。背景目前使用 CSS 与占位图；完整外观预设与简体中文 / English / 跟随系统已在 v0.2 实现。自定义背景文件、字体、快捷键、更多语言与行为偏好安排在 v0.5。预设库操作独立持久化，「应用」先更新外观草稿，再由「保存设置」保存当前外观；语言偏好独立于外观预设。

## Git 与质量工作方式

- 主分支 `main`；功能分支建议 `feat/<topic>`，修复分支 `fix/<topic>`。
- 提交采用 `feat:`、`fix:`、`docs:`、`chore:`，保留依赖锁文件；常规安装使用 `npm ci`。
- Elemental 固定 rev，更新前审阅接口与许可，尝试移除可淘汰补丁并执行游戏回归。
- 本地提交和测试不代表已发布远程版本；项目自己的远程地址由用户创建后设置。
- CI 配置涵盖 Rust 与前端检查，只有实际远程运行结果才代表该平台通过。高 DPI、Linux / macOS 桌面与系统安装包继续单独验收。
