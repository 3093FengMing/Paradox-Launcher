## 自定义设置的扩展原则

每个暴露的设置应确实影响行为并保存；尚未实现的功能显示开发阶段，不做无效开关。
外观设置即时预览，游戏设置需保存后影响下次启动。调整游戏根目录不自动移动文件。
两种界面共享配置、实例和任务状态。风格、主题、强调色、缩放、圆角及背景效果保存于 `Appearance`。
现阶段完成风格切换、背景模糊 / 遮罩 / 侧栏不透明度，正式背景素材与本地文件选择作为后续扩展。
高级参数由 SDK 的参数解析器处理，内存配置为 -Xms / -Xmx 的唯一入口。

v0.2 后增加每实例覆盖、下载并发 / 重试 / 镜像、Java 检测、行为与日志偏好。
v0.5 增加自定义背景文件、字体、预设、快捷键与语言。

## Git 工作方式

- 主分支：`main`；功能分支建议 `feat/<topic>`，修复分支 `fix/<topic>`。
- 提交建议：`feat:`、`fix:`、`docs:`、`chore:`。
- 保留 Cargo.lock 与两份 package-lock.json；常规安装用 `npm ci`。
- SDK 固定 rev；更新时审阅 release / diff，先移除兼容补丁试编译，再做游戏回归。
- 当前只创建本地仓库。用户创建远程后执行 `git remote add origin <自己的仓库地址>` 与 `git push -u origin main`。
- CI 负责 Rust 格式 / clippy / test 和前端生产构建；远程运行结果才代表对应平台已通过。
