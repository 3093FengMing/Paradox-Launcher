This private catalogue is generated from the installed locked `lucide-react` 0.468.0 public CommonJS exports. Extraction keeps each own public export whose value is a member of `Object.values(lucide.icons)`, including concrete aliases, and sorts names by Unicode code point (all names are ASCII). The host still resolves and verifies the actual component identity. Rust embeds the same names.

Source: https://www.npmjs.com/package/lucide-react/v/0.468.0 (ISC license). Run `node ui/scripts/check-ui-suite-icons.mjs --generate` to regenerate after an explicitly accepted dependency change, and run without the flag for deterministic installed-dependency parity. The checker pins the dependency version and prints the extracted names' SHA256; `ui/package-lock.json` records the dependency archive integrity.
